# 滤波器系数计算工具使用说明

## 工具简介

提供两个版本的滤波器系数生成工具：

1. **`filter_calculator_interactive.py`** - 交互式版本（推荐新手使用）
   - 自动询问参数，无需记忆命令
   - 友好的中文提示
   - 可选择保存到文件

2. **`filter_calculator.py`** - 命令行版本（适合批处理）
   - 快速生成多个采样率的系数
   - 适合脚本调用和自动化

## 快速开始

### 方式一：交互式版本（最简单）

```bash
# 直接运行，按提示操作
python tools/filter_calculator_interactive.py
```

**交互流程：**
1. 询问需要哪些采样率（250Hz? 500Hz? 1000Hz? ...）
2. 询问是否使用默认滤波器参数
3. 询问是否保存到文件
4. 自动生成 C 代码

**示例对话：**
```
=== 采样率设置 ===
常用采样率：
  是否需要 250Hz? [y/N]: n
  是否需要 500Hz? [y/N]: y
  是否需要 1000Hz? [y/N]: y
  是否需要 2000Hz? [y/N]: n

是否需要添加其他采样率? [y/N]: n

=== 滤波器参数设置 ===
是否使用默认滤波器参数? [Y/n]: y

是否将结果保存到文件? [y/N]: y
请输入文件名 [filter_coeffs.txt]: my_filters.txt

结果已保存到: my_filters.txt
```

### 方式二：命令行版本（快速）

```bash
# 使用默认采样率 (250Hz, 500Hz, 1000Hz)
python tools/filter_calculator.py

# 指定单个采样率
python tools/filter_calculator.py 500

# 指定多个采样率
python tools/filter_calculator.py 125 250 500 1000 2000

# 保存输出到文件
python tools/filter_calculator.py 250 500 1000 > output.txt
```

## 滤波器设计参数

### 1. 50Hz 陷波滤波器 (IIR Notch Filter)
- **作用**: 去除工频干扰（市电50Hz及其谐波）
- **类型**: IIR 陷波滤波器
- **Q值**: 5
- **带宽**: 约10Hz (45-55Hz区域衰减约-40dB)
- **特点**: 窄带陷波，只影响50Hz附近，不影响有效信号

### 2. 100Hz 低通滤波器 (Butterworth LPF)
- **作用**: 去除高频噪声，保留生物电信号频段
- **类型**: 4阶 Butterworth 低通滤波器
- **截止频率**: 100Hz (-3dB点)
- **阻带衰减**: 24dB/octave (>100Hz区域快速衰减)
- **通带特性**: 0-100Hz平坦响应，波纹<0.1dB
- **实现方式**: 拆分为2个双二阶节（SOS）级联

### 3. 移动平均滤波器参数
- **50Hz陷波窗口 (M)**:
  - 计算：M = 采样率 / 50
  - 作用：通过滑动窗口平均进一步去除工频干扰
  - 示例：500Hz采样率 → M=10点 → 20ms窗口

- **基线漂移窗口 (Q)**:
  - 计算：Q = 采样率 × 0.4秒
  - 作用：消除直流偏移和低频漂移
  - 示例：500Hz采样率 → Q=200点 → 0.4秒窗口

## 信号处理链路

```
原始ADC信号
    ↓
IIR 50Hz陷波  → 去除工频干扰 (50±5Hz)
    ↓
IIR 100Hz低通 → 去除高频噪声 (>100Hz)
    ↓
移动平均陷波  → 进一步去除工频残留
    ↓
基线漂移去除  → 消除直流偏移 (0.4s窗口)
    ↓
输出滤波信号
```

## 滤波效果

| 频率范围 | 滤波效果 | 说明 |
|---------|---------|------|
| 0.5-40Hz | **保留** | 心电、肌电等有效生物电信号 |
| 50Hz | 衰减约-60dB | 工频干扰（IIR -40dB + MA -20dB） |
| >100Hz | 衰减约-24dB/octave | 高频噪声 |
| 直流分量 | **完全消除** | 基线漂移 |

## 输出说明

脚本输出包括：

1. **滤波器设计参数摘要** - Q值、截止频率等
2. **IIR陷波器系数** - C语言格式的 `IIR_50HZ_B` 和 `IIR_50HZ_A` 数组
3. **IIR低通滤波器系数** - 两个双二阶节的系数和增益
4. **移动平均参数** - M_TABLE 和 Q_TABLE 数组
5. **信号处理链路说明** - 完整的滤波流程
6. **采样率映射函数** - 参考实现代码

## 注意事项

### 采样率限制

1. **陷波滤波器**: 50Hz必须小于奈奎斯特频率(采样率/2)
   - ❌ 采样率<100Hz时陷波器可能无效
   - ✅ 推荐采样率≥250Hz

2. **低通滤波器**: 100Hz必须小于奈奎斯特频率
   - ❌ 采样率<200Hz时低通滤波器无法设计
   - ✅ 推荐采样率≥250Hz

### 使用建议

- **心电信号（ECG）**: 推荐500Hz或1000Hz采样率
- **肌电信号（EMG）**: 推荐1000Hz或2000Hz采样率
- **脑电信号（EEG）**: 推荐250Hz或500Hz采样率

## 技术支持

如需修改滤波器参数（Q值、截止频率等），请编辑脚本开头的常量定义：

```python
NOTCH_FREQ = 50      # 陷波中心频率（Hz）
NOTCH_Q = 5          # 陷波品质因数
LPF_CUTOFF = 100     # 低通截止频率（Hz）
LPF_ORDER = 4        # 低通滤波器阶数
BASELINE_WINDOW = 0.4  # 基线漂移窗口时间（秒）
```
