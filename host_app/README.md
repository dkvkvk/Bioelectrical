# 心电采集与 HRV 分析上位机 —— 使用说明

这是我们自己开发的新版上位机，用来替代厂家的 KSEDB 软件。除了原来的
看波形、控制设备功能，还新增了**录制保存**和 **HRV（心率变异性）分析**。

---

## 一、第一次使用（只做一次）

1. 双击 **`安装环境.bat`**，等它显示"安装完成"（需要几分钟）。
   - 如果提示找不到 Python：先去 python.org 安装 Python 3.10 以上版本，
     安装时记得勾选 **Add Python to PATH**，装好后重新双击。
2. 以后每次使用，双击 **`启动上位机.bat`** 就行。

---

## 二、连接设备

软件支持两种连接方式（左上角下拉框切换，已连接时不能切换）：

**方式一：无线蓝牙（默认）**
1. 设备开机，戴好/贴好电极。
2. 点 **「扫描设备」**，等约 6 秒。
3. 下拉框里选中设备（名字叫 BLE_EEG），点 **「连接」**。

**方式二：串口（USB线）**
1. 设备用 USB 线插到电脑（就是平时烧录固件用的那根线、那个口）。
2. 顶部切换为 **「串口（USB线）」**，点 **「刷新端口」**。
3. 下拉框选中设备对应的端口，点 **「连接」**。
   - 串口模式下软件会自动定期给设备发"保活"命令维持数据流，无需手动操作。
   - 串口数据里没有电量和电极脱落信息，这两项会显示"—"。
   - 如果提示串口被占用：先关掉烧录工具、串口助手等正在使用该端口的软件。

两种方式连接成功后顶部圆点变绿，波形开始滚动。后面的录制、分析完全一样。

界面各部分：

| 区域 | 作用 |
|---|---|
| 顶部按钮 | 连接方式切换、扫描/刷新端口、连接、断开 |
| 状态行 | 电量、心率、电极是否脱落、数据批次/坏帧数量 |
| 中间两张图 | 通道1、通道2 实时波形，自动跟随信号幅度；可暂停（暂停后可缩放细看）、可清空、可调时间窗 |
| 右上「设备设置」 | 增益档位、采样率、两通道滤波开关、暂停数据流 |
| 右下「录制与分析」 | 开始/停止录制、分析最近一次录制、录制记录管理 |
| 底部日志 | 软件在做什么、有没有出错（中文提示） |

> 采样率建议用 500 Hz（默认）：设备的滤波就是按 500Hz 设计的。
> 「数据帧（坏 X）」里的坏帧数如果持续上涨，说明蓝牙信号不好，
> 可以把设备挪近一点。

## 三、录一段数据（做 HRV 分析前的准备）

1. 找个安静姿势坐好，正常呼吸，不要说话、不要动（很重要：HRV 对
   动作和伪差很敏感，脏数据会把结果带偏）。
2. 点 **「● 开始录制」**，安静保持 **3~5 分钟**（频域指标至少要 2 分钟
   数据，标准做法是 5 分钟）。
3. 时间到了点 **「■ 停止录制」**，数据自动保存在 **"文档\心电HRV数据\录制"** 文件夹里（系统文档目录下，方便查找和备份）。

---

## 四、HRV 分析

点 **「分析最近一次录制」**（或「分析历史录制…」选以前的记录），会弹出
分析窗口，自动算出 6 张图、一张指标表和一段白话解读：

| 图 | 看什么 |
|---|---|
| 心电波形与QRS定位 | 红色三角是每次心跳的R波，灰点/绿点是每拍的Q点/S点；红色菱形是宽度异常的"宽QRS"——检查心跳找得准不准 |
| 心跳间隔曲线 | 每次心跳间隔随时间的起伏，红叉是被剔除的伪差 |
| 心率趋势 | 逐拍心率（淡点）、1分钟/5分钟平均心率（橙线/绿线），看心率的快慢变化 |
| 频谱 | 心跳变异拆成不同频段（灰=VLF、橙=LF、绿=HF） |
| 散点图 | 相邻心跳间隔的散点分布，越椭圆说明变异越丰富 |
| RR直方图 | 心跳间隔的整体分布形状 |

指标表每个指标带**含义说明**和**参考范围**两列；右侧"白话解读"会把
数字翻译成人话（如"副交感神经活性偏低"），并给出数据质量提示。
算法覆盖：R波检测（Pan-Tompkins类）、QRS波群定位与宽度、时域
（SDNN/SDANN/SDNN指数/三角指数/RMSSD/pNN50等）、频域
（VLF/LF/HF/LF-HF）、非线性（Poincaré、DFA α1/α2、样本熵）、
两种方法互验的心率（逐拍法+频域法）。

> SDANN、SDNN指数、三角指数需要 10 分钟以上的录制才计算，
> 表格里显示"—"不是出错。

点 **「导出全部结果到录制文件夹」** 会把 6 张图、指标表（Excel 可打开）、
逐拍明细（每拍RR间期、Q/S点、QRS宽度）、解读文本全部保存到该次录制的
文件夹里。

> 提示：指标是"数字和趋势"，不是医疗诊断。每个人的基础值不同，
> 最有意义的用法是**和自己的其他记录横向比较**。

### 主界面实时心率

选**心电芯片（KS108x）**时，右侧大字心率默认用**电脑端R波逐拍法**计算
（每2秒更新一次，更准更稳），下方小字同时显示设备算法的数值作对照；
两者应该接近，差得多说明信号质量不好。蓝牙/串口断开或信号太差时自动
回退显示设备算法数值。

## 五、波形显示说明

- 波形**围绕0显示**（去直流）：设备滤波输出本身带直流水平，原始值
  可能整体偏正或偏负。屏幕显示时已自动居中，形态直观；**录制保存的
  仍是原始数据**，分析精度不受影响。
- 波形**自动跟随**：显示范围始终贴着当前信号，电极脱落重贴、幅度
  变化后都会自动收紧/放大，不需要手动调整。
- **暂停显示**：冻结画面后可以用鼠标滚轮放大、拖动查看波形细节，
  点「继续显示」回到实时跟随。
- **清空数据**：清掉屏幕上的波形和统计数字，重新开始（正在进行的
  录制不受影响）。

## 六、录制记录管理

点 **「录制记录…」** 可以查看全部历史录制，支持：

- **分析**：直接对选中的录制做HRV分析（双击列表行也可以）
- **重命名备注**：给录制起个好认的名字（只改显示名，不动数据）
- **删除**：连同该次录制的分析结果一起删除（会先弹确认框）
- **打开文件夹**：在资源管理器里打开该次录制的文件夹

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 扫不到设备 | 确认设备已开机、离电脑 2 米内、没被其他软件（含 KSEDB）连着 |
| 提示蓝牙没打开 | 先打开电脑蓝牙，再点扫描 |
| 串口打不开/被占用 | 关掉烧录工具、串口助手等占用端口的软件后重试 |
| 串口列表里不知道选哪个 | 拔插一下USB线，点「刷新端口」，新出现的那个就是设备 |
| 波形全是直线/乱跳 | 电极没贴好或导联脱落（看状态行"电极"），或增益太低/太高，换个档位试试 |
| 分析提示心跳太少 | 信号太弱或干扰太大：重新贴电极、保持安静、换 360x 默认增益重录 |
| 频域显示"数据不足2分钟" | 录满 5 分钟再分析 |
| 改设置时波形抖动 | 已优化：重复点击相同配置不再下发命令；只改一个通道时另一通道不再受影响（后者需烧录 2026-09-15 后的固件） |

## 八、文件结构（给开发参考）

```
host_app/
├── app.py                 程序入口
├── core/
│   ├── version.py         版本号与软件名（唯一来源，发版改这里）
│   ├── paths.py           数据目录（文档\心电HRV数据，可用环境变量重定向）
│   ├── frame_parser.py    数据帧解析 + CRC8 校验（蓝牙23字节帧 / 串口9字节帧）
│   ├── ble_link.py        蓝牙扫描/连接/订阅/发命令（bleak）
│   ├── serial_link.py     串口收发/保活/字节流重同步（pyserial）
│   ├── recorder.py        录制保存/读取
│   ├── hrv.py             HRV 分析引擎（滤波→R波→QRS定位→RR→时域/频域/非线性/解读）
│   └── demo_source.py     模拟信号源（自动测试/打包自检用，界面上不出现）
├── ui/
│   ├── main_window.py     主界面
│   └── analysis_window.py 分析结果界面
├── packaging/             打包配置（见 packaging/README_云端构建.md）
├── tests/                 自动化测试（python tests/run_all.py）
├── 安装环境.bat / 启动上位机.bat   （源码运行方式，开发者用）
└── 用户数据在 文档\心电HRV数据\    （录制/分析结果/日志，不入库）
```

## 九、给别人安装使用（安装包）

正式分发走 **GitHub 云端构建**：推送代码后自动产出三平台安装包，
Windows 是双击安装的 setup.exe（含许可协议、快捷方式、卸载）。
详见 [packaging/README_云端构建.md](packaging/README_云端构建.md)。

通信协议细节见项目文档 `doc/host_esp32_ble_protocol.md`。

> 固件小知识：2026-09-15 起的固件里，上位机重发**完全相同**的设置命令
> 会被设备直接忽略（不再重置滤波器）。这对串口模式的"保活"很重要——
> 如果设备还在跑旧固件，串口模式下每 20 秒左右心电上会有一次小毛刺
> （软件的伪差剔除会自动处理，不影响大局，但重新烧录固件后可完全避免）。
